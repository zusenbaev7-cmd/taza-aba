# Открытый архив качества воздуха «Таза Аба»

`archive/<город>.csv` — по одной строке на каждые прошедшие местные сутки для 58 городов (38 — Кыргызстан, 20 — Турция).
Пишет GitHub Actions (`.github/workflows/daily-archive.yml`, каждую ночь ~22:40 UTC) скриптом `bot/archive_daily.js`.
Список городов и точек — `bot/archive_cities.json` (центр города, та же точка, что в «Зимах по годам» панели мэрии).
`archive/index.json` — метаданные: источник, лицензия, столбцы, период по каждому городу.

Столбцы: `date` (местная дата), `aqi_mean`, `aqi_max` (US AQI по Open-Meteo), `pm2_5_mean`, `pm2_5_max`, `pm10_mean`, `no2_mean` (мкг/м³),
`hours_pm2_5_over_15` (часов с PM2.5 > 15 мкг/м³), `hours` (часов с данными; сутки с < 20 часами не пишутся).

Важно: это **модельные** значения CAMS (Copernicus) через Open-Meteo, разрешение ~40 км в Кыргызстане и ~11 км в Турции, а не измерения датчиков.
Уже записанные строки не переписываются. История с 2022-12-01 до начала ежедневной записи (2026-10-20) загружена один раз из архива Open-Meteo.
